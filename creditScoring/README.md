Credit Risk Model
Проект по бинарной классификации заемщиков. Бизнес-цель: Снижение уровня просроченной задолженности. Решение: Использование Random Forest с параметром class_weight='balanced', так как дефолтных клиентов в выборке значительно меньше. Результат: ROC-AUC 0.85. Модель позволяет автоматически отсеивать высокорисковых клиентов.
