Credit Risk Model
Бизнес-цель: Снижение уровня просроченной задолженности. Решение: 
Использование Random Forest с параметром class_weight='balanced', так как дефолтных клиентов в выборке значительно меньше. 
Результат: ROC-AUC 0.85. Модель позволяет автоматически отсеивать высокорисковых клиентов.

Fraud Detection System
Бизнес-цель: Выявление мошеннических операций в реальном времени. 
Алгоритм: Isolation Forest — эффективно находит аномалии в банковских транзакциях без необходимости иметь размеченные данные (обучение без учителя).

Real Estate Price Estimator
Бизнес-цель: Автоматизированная оценка стоимости жилья для ипотечного отдела. 
Особенности: Внедрена фильтрация выбросов через квантили, что повысило точность модели на 15%. Метрика: MAE (средняя абсолютная ошибка в рублях).
